# 🚀 VLESS-XHTTP + 3X-UI + AI Mask Site Installer

Автоматический отказоустойчивый скрипт развертывания **VLESS-XHTTP (SplitHTTP)** на порту `443` с панелью **3X-UI**, сертификатом Let's Encrypt и **уникальным сайтом-прикрытием, генерируемым нейросетью** под любую локацию и бизнес в мире.

---

## ⚡ Установка в одну команду

Подключитесь к вашему чистому серверу (Ubuntu 20.04 / 22.04 / 24.04 или Debian 11 / 12) по SSH и выполните:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/dexxdd/custom-AI-VPS-tuner-/main/install.sh)
```

Или альтернативный вариант с сохранением файла:
```bash
curl -sSL https://raw.githubusercontent.com/dexxdd/custom-AI-VPS-tuner-/main/install.sh -o install.sh && sudo bash install.sh
```

## ✨ Ключевые возможности

1. **🧠 Генерация сайта через ИИ на родном языке города:**
   - Нейросеть пишет сайт компании на официальном языке локации (Токио -> японский, Берлин -> немецкий, Париж -> французский, Рим -> итальянский и т.д.).
   - Автоматический подбор шрифтов, карточек услуг, телефона, адреса и копирайта 2026 года.
   - Бесплатно, без API-ключей, без регистрации.

2. **🎲 Функция «Авторандом на [Enter]»:**
   - Не хотите придумывать название и нишу? Просто нажимайте `[Enter]` в терминале — скрипт сам выберет случайную стильную компанию мирового уровня.

3. **🛡️ 100% Отказоустойчивость:**
   - Автоматическое снятие системных блокировок менеджера пакетов (`apt lock`).
   - Защита от конфликта портов (отключение фонового `apache2`).
   - Автоопределение активного порта SSH (никакого риска заблокировать доступ через фаервол).
   - Интерактивный цикл повтора при ошибках DNS или Cloudflare Proxy (не нужно начинать установку сначала).
   - Встроенный автономный процедурный генератор (сработает, если у шлюза ИИ пропадет связь).

4. **🔒 Топовая маскировка и безопасность:**
   - Протокол: **VLESS-XHTTP** (порт 443, TLS Let's Encrypt, uTLS Edge, путь `/api/`, случайный padding `100-1000`).
   - Панель управления 3X-UI защищена фаерволом UFW (доступ только с вашего IP или по белому списку).
   - Веб-сервер Nginx на порту 80 с раздачей готового сайта-маскировки.
   - Готовая ссылка подключения и QR-код прямо в окне консоли.
